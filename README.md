# 🏡 Boston House Price Prediction

A Machine Learning project that predicts house prices using housing data, data visualization, and regression algorithms.

## 🛠️ Software and Tools Requirements

1. 🐙 [GitHub Account](https://github.com/)
2. ☁️ [Heroku Account](https://heroku.com/)
3. 💻 [Visual Studio Code (VS Code)](https://code.visualstudio.com/)
4. 🔧 [Git CLI](https://git-scm.com/book/en/v2/Getting-Started-The-Command-Line)
5. 🐍 [Python](https://www.python.org/)
6. 📓 [Jupyter Notebook](https://jupyter.org/)

## ⚙️ Setting Up the Python Environment

### 1. Create a Virtual Environment

A virtual environment isolates the Python packages and dependencies required for your project.

```powershell
python -m venv ML
```

### 2. Activate the Environment

For Windows PowerShell:

```powershell
.\ML\Scripts\Activate.ps1
```

### 3. Install Required Libraries

Install the essential libraries for data analysis, visualization, and Machine Learning.

```powershell
python -m pip install --upgrade pip
python -m pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```powershell
jupyter notebook
```

### 📚 Libraries Used

 Library  Purpose 

 NumPy -  Numerical calculations 
Pandas - Data manipulation and analysis 
Matplotlib -  Data visualization 
Seaborn -  Statistical visualization |
Scikit-learn -  Machine Learning models and evaluation 
Jupyter - Interactive coding and experimentation |

## 🎯 Project Objectives

- Explore and analyze housing data.
- Visualize relationships between housing features and prices.
- Preprocess data and prepare training and testing sets.
- Train and evaluate regression models.
- Predict house prices using unseen data.

## 🚀 Getting Started

Clone the repository, navigate to the project folder, and follow the environment setup instructions above.

**Note:** Heroku is an optional deployment platform, and the original Boston Housing dataset has known limitations. Use a dataset that is appropriate for your learning goals and be mindful of its historical biases.
